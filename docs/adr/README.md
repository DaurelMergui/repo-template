# Architecture Decision Records

Numbered `NNNN-slug.md`, append-only. Write one only when a decision is hard to reverse, surprising without context, and a real trade-off.

```md
---
status: proposed   # proposed | accepted | deprecated | superseded by ADR-NNNN
---
# Short title of the decision

1-3 sentences: context, what we decided, and why.
```

Never edit an accepted ADR; supersede it with a new one and update `INDEX.md`.
